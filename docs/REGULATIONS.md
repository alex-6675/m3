# REGULATIONS.md — регламенты пространства m3 (нормы индустрии)

## Вход для внешнего
Вы в проекте «Мои записки» (m3). Порядок чтения: README →
ABOUT_USER.md → STAGES.md → этот файл. Соседи: context-vkru
(донор ядра, архив), mem-2026 (Astro-сайт, приоритет).

## Роли
- Пользователь: смыслы, приоритеты, вердикт по картинке.
  НЕ оператор инструментов агента.
- Проектировщик (диалог Qwen): зона кода, схемы, задания, raw-гейт.
- Кодер: тексты, коммиты, отчёты; одна задача за ответ.
- Агент (SourceCraft/MCP): зрение CDP 9222, диагностика без пользователя.

## Коммиты (Conventional Commits)
Типы: feat, fix, docs, chore, refactor, diag, test.
Скоупы: ext, site, scripts, docs. Пример:
  fix(ext): картотека ПЕР/СОО [TASK-0021]
Ссылка на TASK-NNN обязательна для кода.

## Задачи и отчёты
- TASK-NNN: номер, суть, форма, «STOP» в конце текста задачи.
- Отчёт: файлы, версия manifest, что тронуто/НЕ тронуто.
- Фикс и refactor НЕ в одном коммите. Одна копия кода;
  при переносе — provenance-хэш.

## Лимиты
Л1 движений пользователя за цикл: 0 или 1. Л2 ≤2 итераций на дефект.
Л3 слепая диагностика запрещена. Л4 короткие тексты.
Л5 артефакт только при отдаче. КК = отдача/(лента+ресурсы);
цикл КК≤0 не повторяется.
